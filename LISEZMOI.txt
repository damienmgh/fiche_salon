1. MISE EN LIGNE (une seule fois)
L'application doit être servie en HTTPS par un serveur web pour s'installer et fonctionner hors ligne.
Options :
 a) Service informatique MGH : copier le dossier sur un serveur web, par exemple https://salon.mgh.be/
 b) Azure Static Web Apps (Microsoft, offre gratuite) : solution recommandée si MGH travaille sous Microsoft 365. Voir 1.2.
 c) Netlify (gratuit) : créer un compte, glisser le dossier sur app.netlify.com/drop, récupérer l'adresse https fournie.
 d) GitHub Pages (gratuit) : dépôt contenant les 6 fichiers, activer Pages dans les paramètres du dépôt.

1.1 SHAREPOINT : CE QUI EST POSSIBLE, CE QUI NE L'EST PAS
SharePoint Online ne peut pas faire tourner l'application :
 - SharePoint Online n'affiche pas les fichiers .html dans le navigateur : il les télécharge, pour raison de sécurité, sans réglage possible au niveau du tenant.
 - Le contournement par renommage en .aspx exige que le « script personnalisé » soit autorisé sur le site au moment du dépôt. Microsoft désactive ce réglage par défaut et l'applique strictement depuis septembre 2024. À ne pas utiliser.
 - Même affichée, l'application ne pourrait pas s'installer ni fonctionner hors ligne : le service worker (sw.js) n'est pas exécutable depuis une bibliothèque SharePoint.
 - Ouvrir index.html téléchargé depuis SharePoint sur la tablette ne fonctionne pas non plus : pas d'installation, pas de mode hors ligne, pas de réception depuis HiNoter, stockage des fiches non garanti.

SharePoint reste utile pour DISTRIBUER et CENTRALISER :
 A. Distribution du lien et de la documentation
   1. Créer un dossier « Application Fiche salon » dans le site SharePoint de l'équipe commerciale.
   2. Y déposer ce LISEZMOI.txt, le ZIP de l'application (archive de référence) et un fichier « Lien application.url » ou une page d'actualité contenant l'adresse https de l'application (hébergée selon a, b, c ou d).
   3. Partager le dossier avec les commerciaux (DM, LM, HH, JD, LMA) en lecture seule.
   4. Sur la tablette : ouvrir l'application SharePoint ou Teams, toucher le lien, il s'ouvre dans Chrome, puis installer (voir 2).
 B. Centralisation des fiches après le salon
   1. Créer un dossier « Salons / [nom du salon] » dans la bibliothèque, partagé en modification avec les commerciaux.
   2. Installer OneDrive ou SharePoint sur la tablette, connecté au compte Microsoft 365 MGH.
   3. Dans l'application : « PDF de toutes les fiches », « Exporter / sauvegarder > Partager le CSV » ou « Partager la sauvegarde », puis choisir OneDrive dans le menu de partage Android et sélectionner le dossier du salon.
   4. Un responsable fusionne les CSV de chaque commercial dans Excel, ou importe les sauvegardes .json sur un même appareil (« Importer une sauvegarde »).

1.2 HÉBERGEMENT DANS L'ENVIRONNEMENT MICROSOFT : AZURE STATIC WEB APPS
À confier au service informatique, qui dispose des droits sur l'abonnement Azure de MGH.
   1. Portail Azure > Créer une ressource > Static Web App. Offre : Free. Région : Europe de l'Ouest.
   2. Source de déploiement : « Other » (dépôt manuel), ou un dépôt GitHub / Azure DevOps contenant les 6 fichiers.
   3. Déposer les 6 fichiers à la racine du site (outil SWA CLI, Visual Studio Code avec l'extension Azure Static Web Apps, ou pipeline du dépôt).
   4. Récupérer l'adresse https fournie (…azurestaticapps.net) ou associer un sous-domaine MGH, par exemple salon.mgh.be (Domaines personnalisés, certificat HTTPS gratuit fourni par Azure).
   5. Optionnel : restreindre l'accès aux comptes Microsoft MGH via l'authentification intégrée (Microsoft Entra ID). À valider par l'informatique selon l'offre retenue : la restriction fine aux seuls comptes du tenant peut nécessiter l'offre Standard. Une fois connecté une première fois, l'application reste utilisable hors ligne.
   6. Publier l'adresse dans SharePoint (voir 1.1 A).
Mise à jour de l'application : redéployer les fichiers et changer VERSION dans sw.js.

2. INSTALLATION SUR LA TABLETTE ANDROID
 - Ouvrir l'adresse dans Chrome.
 - Menu (3 points) > « Installer l'application » ou « Ajouter à l'écran d'accueil ».
 - L'icône MGH apparaît. Ouvrir une fois avec réseau : l'application est ensuite disponible sans wifi.

3. AVANT LE SALON
 - Barre du salon (en haut de la liste) : « + Nouveau salon » > nom, nombre de jours (1 à 10), date du J1. Les jours suivants se remplissent automatiquement et restent modifiables un par un.
 - Roue dentée : initiales par défaut, email destinataire, application d'enregistrement.

3.1 NAVIGUER ENTRE LES SALONS
 - Flèches ‹ et › : salon précédent ou suivant, dans l'ordre chronologique.
 - Toucher le nom du salon : liste de tous les salons avec leurs dates et leur nombre de fiches. Toucher un salon pour l'ouvrir, crayon pour le modifier (nom, jours, dates) ou le supprimer.
 - La liste, les filtres, le CSV et le « PDF de toutes les fiches » portent sur le salon affiché. La numérotation des fiches repart à 1 pour chaque salon.
 - Fiche créée dans le mauvais salon : dans la fiche ouverte, changer le salon dans le menu « Salon » en haut. La fiche reçoit le numéro suivant du salon choisi.
 - Supprimer un salon supprime aussi ses fiches : faire une sauvegarde avant.

4. UTILISATION
 - « Nouvelle fiche » : nouveau contact. Enregistrement automatique à chaque saisie.
 - « Terminer » : contrôle la société et marque la fiche complète. Puis « Nouvelle fiche » pour le contact suivant.
 - Photo de la carte de visite : section Identification.
 - « Partager » : email, WhatsApp, Teams, Drive… avec texte de la fiche, CSV et photo.
 - « PDF » (fiche ouverte) : impression ou enregistrement PDF de la fiche.
 - « PDF de toutes les fiches » (liste) : récapitulatif des contacts puis une page par fiche. Les filtres et la recherche en cours s'appliquent. Choisir « Enregistrer au format PDF » dans la fenêtre d'impression.
 - Supprimer : icône corbeille sur chaque fiche de la liste, ou bouton corbeille dans la fiche ouverte. Confirmation, puis « Annuler » possible pendant 7 secondes.
 - Langue : boutons FR / NL / EN en haut à droite (français par défaut, choix mémorisé). Le partage, le PDF et le CSV sortent dans la langue affichée.
 - Dictée (section en haut de la fiche) : bouton « Dicter » (micro de la tablette, connexion internet nécessaire), choix de la langue parlée FR/NL/EN, ou collage d'une transcription. « Remplir la fiche depuis le texte » propose les valeurs détectées à cocher avant report.
 - HiNoter (préconfiguré, package com.recordpro.audiorecord) : le bouton « Ouvrir HiNoter » de la section Dictée lance l'application. Pour une autre application, modifier le nom et le package dans les paramètres. Dans cette application, « Partager » la transcription puis choisir « Fiche salon » : le texte arrive dans la fiche en cours ou dans une nouvelle fiche, puis l'analyse démarre.
 - Liste : recherche, filtres A/B/C, brouillons, non partagées.
 - « Exporter » : CSV Excel et PDF des fiches du salon affiché.
 - « Sauvegarder » : sauvegarde complète de tous les salons et de toutes les fiches, photos comprises. Un point orange sur le bouton signale des modifications non sauvegardées.
    · « Enregistrer dans un fichier » : choix de l'emplacement si la tablette le permet (stockage interne, carte SD, OneDrive ou Drive s'ils apparaissent dans le sélecteur), sinon dossier Téléchargements.
    · « Envoyer vers OneDrive » : menu Partager > OneDrive > choisir le dossier (par exemple SharePoint / Salons). Nécessite l'application OneDrive installée et connectée au compte MGH. Selon la version de Chrome, le fichier peut partir au format .txt : son contenu est identique et il se restaure de la même façon.
    · « Importer une sauvegarde » : restaure depuis un fichier .json ou .txt (tablette ou OneDrive). N'écrase rien : seuls les salons et fiches manquants sont ajoutés.

5. PRÉCAUTIONS
 - Les fiches sont stockées uniquement sur la tablette. « Sauvegarder » chaque soir de salon, de préférence vers OneDrive.
 - Ne pas vider les données du site dans Chrome : cela efface les fiches.
 - Mise à jour de l'application : remplacer les fichiers sur le serveur et changer VERSION dans sw.js.
